# 考研英语二 · 学习台

一个单文件、零依赖、可离线使用的考研英语二刷题工具。内置 **2010–2026 历年真题共 143 篇**（阅读理解 68 / 完形填空 15 / 新题型 15 / 翻译 15 / 写作 30），支持在线云同步与本地 localStorage 双模式。

## 使用方式

无需构建，直接用浏览器打开 `kaoyan-english.html` 即可（或通过任意静态服务器托管）。

## 功能

- **真题练习**：按题型选择 → 年份筛选 / 关键词搜索 → 答题（客观题自动判分，主观题自评）→ 答案解析 + 参考译文 → 保存学习记录
- **阅读查词**：点击阅读段落中的任意单词查释义，一键加入生词本（内置考研高频词词典 + 有道在线兜底）
- **今天要处理**：自定义每日学习计划，支持逾期提醒与完成打卡
- **学习统计**：累计练习、客观正确率、题型掌握度、近 7 天趋势、薄弱题型提醒、连续打卡
- **生词本**：手动添加 / 按掌握度（生疏、模糊、掌握）筛选循环
- **数据管理**：JSON 导出备份 / 导入恢复 / 一键清空；在线模式多设备自动同步

## 目录结构

```
kaoyan-english.html   # 全部界面与逻辑（单文件应用）
papers/*.json         # 历年真题原始数据（已内联进 HTML，作为数据源存档）
papers/extra-papers.js
schema.json
```
