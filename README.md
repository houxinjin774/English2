# 考研英语二 · 学习台

一个单文件、零依赖、可离线使用的考研备考工作台：**真题练习 + 目标打卡 + 专注时钟 + 生词刷词 + 学习统计**。内置 2010–2026 历年真题共 **153 篇**，支持亮暗双主题，可作为 PWA 安装到手机桌面。

- 在线使用：**https://houxinjin774.github.io/English2/**
- 安卓安装：用 Chrome/Edge 打开上面的链接 → 菜单 →「安装应用 / 添加到主屏幕」

## 功能总览（五个模块）

| 模块 | 说明 |
| --- | --- |
| 真题练习 | 按题型/年份筛选与搜索，客观题自动判分，主观题自评，错题解析与全文翻译 |
| 目标打卡 | 有终点、有总量的目标（如背词 3000 个）；每日打卡、连续天数、预计完成日、35 天热力图、周报复盘 |
| 专注时钟 | 随机提示音专注法：3~5 分钟随机提示 → 闭眼休息 → 90 分钟后长休息；专注时长一键记入目标打卡 |
| 生词本 | 卡片式刷词（不认识/模糊/认识），自动发音，队列自动聚焦未掌握单词 |
| 学习统计 | 累计练习、客观正确率、题型掌握度、近 7 天趋势、薄弱提醒、连续打卡 |

## 使用方式

无需构建，直接打开 `kaoyan-english.html` 即可（或通过任意静态服务器托管）。数据保存于浏览器 localStorage（`wb_ky2_*`），建议定期在 ⚙ 数据管理里「导出 JSON 备份」。

## 目录结构

```
kaoyan-english.html   # 全部界面与逻辑（单文件应用）
index.html            # 根地址跳转页
manifest.json / sw.js / icon-*.png   # PWA（安卓可安装）
papers/*.json         # 历年真题原始数据（已内联进 HTML，作为数据源存档）
```

## 版本与回退

| 版本 | Tag | 说明 |

| v7 独立版（融合前） | `v7-premerge` | 真题 + 生词 + 统计 |

回退方法（本地执行）：

```bash
# 查看历史版本
git log --oneline
# 把 main 回退到融合前（保留历史，安全）
git revert --onto v7-premerge main   # 或直接 checkout 标签查看
git checkout v7-premerge             # 仅查看/运行旧版
```

也可在 GitHub 仓库页面 Releases/Tags 处下载 `v7-premerge` 的源码直接打开使用。
