# 考研英语二 · 学习台

一个单文件、零依赖、可离线使用的考研英语二刷题与背词工具。内置 **2010–2026 历年真题共 153 篇**（完形填空 17 / 阅读理解 68 / 新题型 17 / 翻译 17 / 写作 34），支持在线云同步与本地 localStorage 双模式、亮暗双主题。

## 使用方式

无需构建，直接用浏览器打开 `kaoyan-english.html` 即可（或通过任意静态服务器托管）。

## 功能

- **真题练习**：题型 → 年份筛选 / 关键词搜索 → 答题（客观题自动判分，主观题自评）→ 答案解析 + 全文翻译 / 参考译文 / 参考范文 → 计入学习记录
- **新题型原文阅读**：多项对应与段落小标题均附原文卡片（可点击查词、可展开全文翻译）
- **写作图表**：2024/2025 大作文图表以数据渲染，附参考范文
- **阅读查词**：点击文章中的任意单词查释义，一键加入生词本（内置高频词词典 + 有道在线兜底）
- **刷单词**：卡片式刷词（参考「不背单词」）：看词想义 → 翻面 → 不认识 / 模糊 / 认识；自动发音（浏览器语音合成）；队列自动聚焦未掌握单词，每轮结束给小结
- **今天要处理**：自定义每日学习计划，逾期提醒与完成打卡
- **学习统计**：累计练习、客观正确率、题型掌握度、近 7 天趋势、薄弱题型提醒、连续打卡
- **初试倒计时**：按「当年 12 月倒数第二个周六」动态计算（2027 初试为 2026-12-19），考完自动滚动到下一年
- **数据管理**：JSON 导出备份 / 导入恢复 / 一键清空；在线模式多设备自动同步
- **主题**：浅色 / 深色 / 跟随系统三态切换，顶栏一键循环
